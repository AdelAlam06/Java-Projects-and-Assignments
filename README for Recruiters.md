# Java-Projects-and-Assignments

In this folder I have listed all the various skills I have learned of regarding java. I have labelled them in respect to what they represent most in the said file.

Most of these files require a test file to run on so it will not work independently. I did not provide the test case files because those are not my property so I left them out on purpose. I uploaded these programs to demonstrate my knowledge and understanding regarding specific topics, primarily focusing on object oriented programming.

The two most important files that are able to run is Project 1 and Project 2. Both of these projects demonstrate the development of my learning of Java in university and I want to highlight them because they demonstrate all my skills up to this point. 

I suggest using visual studio code to run both of these projects because that is what I built them on. Project 1 is a student management system that keeps track of student related information. Project 2 is a racing game but is a bit finnicky with the interface, so I recommend once you start running the program, just stretch the popup window and all the buttons should appear normally (there should be 3 buttons on launch). From there feel free to play the game!

For project 1 run ProjectOneTester.java

For project 2 run Project2Runner.java
